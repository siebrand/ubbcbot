# Implementation Prompts

This folder contains prompts for implementing the Telegram Beer Ordering Bot.

## Recommended Approach: Staged Implementation

### Stage 1: Core Infrastructure
**File:** `stage1-core-infrastructure.md`
- Basic bot functionality
- AWS infrastructure setup
- Core data models
- Essential commands

### Stage 2: Advanced Features  
**File:** `stage2-advanced-features.md`
- Multi-group publishing
- Discount system
- Image management
- Enhanced business logic

### Stage 3: Operations & Compliance
**File:** `stage3-operations-compliance.md`
- Delivery management
- Audit logging
- Reporting features
- Production readiness

## Alternative: Single Implementation
**File:** `single-complete-implementation.md`
- Complete system in one go
- Higher complexity and risk
- Use only if you prefer all-at-once approach

## Usage
1. Start with Stage 1 and test thoroughly
2. Once Stage 1 is working, proceed to Stage 2
3. Complete with Stage 3 for full production system
4. Each stage builds on the previous one

## Dependencies
- Ensure you have access to requirements.md and aws-architecture.md
- Admin user ID: 15005473 must be configured
- AWS account with appropriate permissions required
